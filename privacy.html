数据处理方式

奶猫妙控通过本地网络连接你的 iPhone 与 Mac。应用不要求注册账号，也不运营用于转发控制指令的云端服务。

本机保存的数据

布局、配对信息、设备名称和应用设置保存在你的设备上。iOS 主应用与小组件会通过同一 App Group 共享连接状态。

本地网络与屏幕画面

应用使用 Bonjour 查找同一局域网内的 Mac。控制指令在已配对设备之间传输；Mac 屏幕预览只对通过配对认证的连接开放，并且需要你主动授予 macOS 屏幕录制权限。

系统权限

Mac 端需要辅助功能权限才能执行快捷键、鼠标和跨应用操作。屏幕录制和 iPhone 麦克风权限仅在你使用对应功能时申请，均可在系统设置中随时关闭。

第三方服务

官网由 Vercel 托管，安装包通过 GitHub Releases 分发。这些服务可能按照各自的隐私政策记录基础访问日志。应用本身不集成广告或跨应用追踪 SDK。

联系我们

如对隐私说明有疑问，可在 GitHub Issues 提交问题。
