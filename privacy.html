Privacy

隐私说明

更新日期：2026 年 8 月 31 日

数据处理方式

奶猫妙控通过本地网络连接 iPhone 或 iPad 与 Mac，不要求注册账号，也不使用云端转发控制指令

本机保存的数据

小键盘、配对信息、设备名称和应用设置保存在设备上，主应用与小组件通过同一 App Group 共享连接状态

购买与订阅

Pro 的购买、恢复、续订、取消与退款由 Apple 处理。应用只读取 StoreKit 验证后的有效权益，不接触或保存银行卡、账单地址和 Apple 账户密码

iCloud 同步

iCloud 同步目前标记为后续 Pro 更新。功能上线并由你启用后，布局与设置会通过你的 iCloud 账户在 Apple 设备之间同步；奶猫妙控不会把这部分数据用于广告

本地网络与屏幕画面

应用使用 Bonjour 查找同一局域网内的 Mac，控制指令仅在已配对设备之间传输，屏幕预览需要 macOS 屏幕录制权限

系统权限

Mac 端需要辅助功能权限才能执行快捷键、鼠标和跨应用操作，屏幕录制和麦克风权限仅在使用对应功能时申请，可随时关闭

第三方服务

官网由 Vercel 托管，安装包通过 GitHub Releases 分发，这些服务可能记录基础访问日志，应用不集成广告或跨应用追踪 SDK

联系我们

如有疑问，可在 GitHub Issues 提交问题
