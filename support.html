奶猫妙控

Support

连接不上时，先看这里。

适用于 macOS 13+ 与 iOS 17+

安装 Mac 端

从 GitHub Releases 下载 Universal DMG，打开后将“奶猫妙控”拖入“应用程序”文件夹。首次运行请按提示完成系统验证。

允许控制 Mac

打开“系统设置 → 隐私与安全性 → 辅助功能”，允许奶猫妙控。菜单栏颜文字显示 ^w^ 时代表已经连接并可控制。

扫描配对二维码

确认 Mac 与 iPhone 或 iPad 使用同一 Wi‑Fi。打开 Mac 菜单栏中的奶猫妙控，再从“设备”页面扫描二维码。也可以长按 App 图标选择“扫码配对”。

为什么没有屏幕画面？

屏幕预览需要单独授予 macOS 屏幕录制权限；这不会影响普通按键、旋钮、触控板和媒体控制。授权后请重新打开 Mac 端。

仍然需要帮助

请在 GitHub Issues 描述 macOS/iOS 版本、菜单栏显示的颜文字，以及问题发生在哪一步。不要粘贴配对码或其他敏感信息。
