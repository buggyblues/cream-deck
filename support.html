奶猫妙控

Support

使用帮助与连接指南

适用于 macOS 13+ 与 iOS 17+ / iPadOS 17+

1. 安装 Mac 端

从 GitHub Releases 下载 Universal DMG 安装包，打开后将“奶猫妙控”拖入“应用程序”文件夹。首次运行时请按系统提示完成安全性验证。

2. 授予辅助功能权限

打开 Mac 的“系统设置 → 隐私与安全性 → 辅助功能”，勾选并允许“奶猫妙控”。当菜单栏图标显示颜文字 ^w^ 时，即代表辅助权限就绪且设备已成功连接。

3. 扫描配对二维码

确保 Mac 与 iPhone 或 iPad 连接到同一个 Wi-Fi 局域网。点击 Mac 菜单栏中的奶猫妙控图标展示二维码，在手机端打开“设备与配对”页面扫描即可；亦可在手机桌面长按 App 图标快速选择“扫码配对”。

4. 开启屏幕画面串流权限

若需使用低延迟屏幕实时预览，请在 Mac 的“系统设置 → 隐私与安全性 → 屏幕录制”中为奶猫妙控授权。常规按键、旋钮、触控板与快捷键不受此权限影响。

5. 购买与恢复 Pro 会员

请在 iPhone 或 iPad 端进入“设置 → 奶猫妙控 Pro”选择套餐购买或点击“恢复购买”。所有交易与订阅均由 Apple App Store 托管，Mac 端仅作状态展示，绝不重复收费。

6. 获取更多协助与反馈

如遇其他问题，欢迎前往 GitHub Issues 提交反馈。建议附上你的 macOS 与 iOS 版本、菜单栏状态及复现步骤（请勿公开粘贴敏感配对信息）。
